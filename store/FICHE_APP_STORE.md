## Questionnaire de confidentialité d'App Store Connect

À la question « Collectez-vous des données à partir de cette app ? », répondre **Non**. Justification, vérifiable dans le code :

- aucune bibliothèque d'analyse, de publicité ou de rapport de plantage (voir `app/package.json`) ;
- aucune requête réseau : le contenu est dans l'app, les rappels sont des notifications locales ;
- la sauvegarde est dans le dossier privé de l'app (comprise dans la sauvegarde iCloud de l'iPhone si l'utilisateur l'a activée, ce qui relève d'Apple et non de l'app) ;
- l'export de progression n'envoie rien : il ouvre la feuille de partage d'iOS.
